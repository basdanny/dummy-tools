# Dummy Apps

This repository contains a collection of small (Windows) apps.

## Apps

* [Image Compressor](dummy-image-compressor): A Windows app that can compress JPEG image files.

* [Folders Sync](dummy-folders-sync): A Windows app that can synchronize the contents of two folders.

* [Caffeina](Caffeina): An app that keeps Windows awake.

* [PDF Merge](dummy-pdf-merge) An app that allows to merge multiple PDF files and images into a single PDF document.
